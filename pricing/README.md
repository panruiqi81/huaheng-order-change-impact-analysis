# 华衡智造 · 订单变更影响核对助手 —— 企业报价包

按《FDE 企业报价与 ROI 测算》课件口径，为本项目（九阶段训练的同一项目）做的一套报价包。所有数字由 [`tools/build_pricing.ps1`](tools/build_pricing.ps1) 一次算出，各表之间可以互相复算。

> 口径提醒：华衡是**合成业务现场**，客户侧的月变更单量、冲突损失、岗位人数、月薪在案例里都没有记录。下文凡标“假设”的数都是为完成测算设定的，不是事实；签约前须由客户提供基线数据后重算。模型与算力单价采用课件口径（2026-11-26 核验），正式报价前按厂商实时价格复核。

## 结论先看这里

| 项 | 数值 | 出处 |
|---|---|---|
| 人天合计 | **62 人天**（工作包 52 + 整体缓冲 20% 取整 10） | 02 表 |
| 人力成本（成本口径） | 104,929 元（加权 1,692 元/天） | 02 表 |
| 模型费 | 基准档 **0.31 元/月、3.69 元/年** | 03 表 |
| 部署推荐 | **云端 API**（脱敏后可出内网为前提） | 04 表 |
| 一次性实施费 | **159,978 元** | 06 表 |
| 年服务费 | **28,181 元/年** | 06 表 |
| 首年合计 / 续年 | **188,159 元 / 28,181 元** | 06 表 |
| 客户首年 ROI | **−34.1%**，回本 18.2 个月，三年 ROI 52.2% | 05 表 |

三点需要讲清楚：

1. **模型费可以忽略，钱花在系统集成与规则工程上。** 核对结论由确定性规则得出，模型只负责把结构化结果写成一线可读的说明，月 40 份报告只用约 17.6 万 Token。这与课件案例三的结论相同：客户买的不是 Token，是把流程真正跑通的集成与规则。
2. **报价以成本口径为基数，只加成一次。** 练 2 的对外人天单价已经含 25% 成本加成；若把它再放进“成本 × (1 + 风险预留) × (1 + 加成)”会重复计取。因此实施费 = (人力成本 + 开发测试环境 + 差旅) × 1.15 × 1.25，实际毛利率 30.4%。02 表同时列出两种口径，需要按课件拼装器原样填写时取“对外口径”一列。
3. **ROI 不好看，而且主要靠一个假设撑着。** 只算工时节省（4,032 元/年）时年净收益为负，不回本，与仓库阶段 04 的结论一致。基准情景能回本，靠的是“每年避免 12 次版本冲突、单次损失 2 万元、降低 50%”这一项假设；保守情景（收益 −30%）三年 ROI 仅 6.5%。签约前必须向客户索取冲突损失的历史记录。

## 复算

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File pricing/tools/build_pricing.ps1
```

脚本末尾会打印 8 项咬合自检，全部“通过”即各表一致。改口径（如月薪、缓冲率、业务量）只需改脚本顶部的参数后重跑。
